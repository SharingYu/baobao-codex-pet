# v0.2.0-alpha · 空壳运行器与独立内容包

本版把程序、宠物和道具拆成可分别安装、升级与售卖的交付物。

## 发布资产

- `PetDesktop-0.2.0-alpha-x64.exe`：不含任何宠物或道具的 Windows x64 运行器。
- `baobao.petpack`：包包示例宠物包。
- `feifei.petpack`：菲菲示例宠物包。
- `starter-play-kit.itempack`：鲑鱼零食、毛线球和纸箱小屋的独立道具包。
- `SHA256SUMS-v0.2.0-alpha.txt`：以上文件的 SHA-256。

## 新增

- 首次启动明确显示空壳引导，不再回退到内置角色。
- `.petpack` 与 `.itempack` 分目录原子导入，支持界面内查看和移除已安装内容。
- 所有食物和玩具图片都来自道具包；运行器只实现白名单互动行为。
- 宠物先靠近屏幕工作区底边，沿边缘跑动，再跳回桌面。
- 逗玩模式使用局部交互区并在 30 秒后自动收起，不会长时间吞掉整个桌面的点击。
- 打包校验会拒绝把 `pets/`、`petpacks/` 或 `itempacks/` 内容带入运行器。

## 安装顺序

1. 运行 `PetDesktop-0.2.0-alpha-x64.exe`；安装后从桌面快捷方式或“开始”菜单启动。
2. 从空壳卡片导入 `baobao.petpack`。
3. 通过底部内容包管理按钮导入 `feifei.petpack` 和 `starter-play-kit.itempack`。
4. 用“摸摸、投喂、玩具、边缘、安静”完成一次互动闭环。
5. 从内容包管理区选择“退出程序”，或右键系统托盘图标选择“退出”。

同 ID 内容包不会覆盖现有安装。升级前先在内容包管理区移除旧包，再导入新包。

公开 Alpha 未使用商业代码签名，SmartScreen 可能显示“未知发布者”。请只从本仓库 Release 下载，并用 `SHA256SUMS-v0.2.0-alpha.txt` 核对文件。完整步骤见 [Windows 使用指南](../user-guide.md)。

## 边界

本版实现的是屏幕工作区边缘，不会识别第三方程序窗口或页面正文。前台窗口几何轨道属于下一阶段的可选 Windows 适配器；页面内容识别必须另行授权并默认关闭。

这是公开 Alpha：底部互动条为避免点击穿透使用约 0.24 秒的本地输入缓冲；指针离开互动条后，透明桌面会随即恢复点击穿透。正式版计划将互动条拆成独立小窗口，彻底隔离桌面输入。
