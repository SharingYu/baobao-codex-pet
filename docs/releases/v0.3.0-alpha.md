# Pet Desktop Companion v0.3.0-alpha

这是面向真实用户安装与定制交付闭环的第三个公开 Alpha。运行器继续保持空壳：安装包不内置包包、菲菲或道具，用户分别导入 `.petpack` 与 `.itempack`。

## 主要变化

- 新增“宠物小屋”：用真实宠物缩略图卡片选择当前互动对象，并通过每张卡片的“桌面显示”开关单独控制显隐。
- 摸摸改为两阶段操作：先点击“摸摸”进入手掌模式，再点击宠物的头、背、尾巴或身体；不同部位触发不同动作与亲密度奖励。
- 食物和玩具均支持手动收起、再次点击切换，以及 30–90 秒自动结束，避免道具长期留在桌面。
- 新增独立亲密度与五级养成：摸摸、投喂和有效玩耍会增加亲密度，并逐级解锁零食、玩具；服装能力计划在后续版本加入。
- 移除主动“边缘”按钮。拖动宠物到普通 Windows 窗口顶边时，程序仅依据窗口矩形把顶边当作平台，宠物会被动吸附、行走、跟随窗口并在平台消失时落回桌面。
- 包包、菲菲各新增摸头、摸背、摸尾和进食四组互动动画，每组 8 帧；资源包依旧不包含原始照片、视频、EXIF 或社交平台水印。
- 状态升级为 v2：分别保存宠物显隐、当前互动对象、位置、亲密度、每日次数、互动条显隐与平台开关；旧存档会自动迁移。
- 托盘可独立显示或隐藏互动条；隐藏互动条不影响宠物陪伴，双击托盘图标可恢复，状态会随存档保存。
- 新增[宠物风格目录](../pet-style-catalog.md)，提供 S01–S04 客户选型、Identity/Style Lock、动作帧约束与整包视觉 QA。

## 隐私边界

只有在用户开启窗口平台互动时，窗口 watcher 才会运行，并且只在本机读取顶层窗口的句柄、进程 ID 和几何矩形；关闭开关会立即停止扫描。它不读取窗口标题、正文、控件树、网页 DOM、截图、OCR 或键盘输入，也不会上传窗口列表。

## 安装与导入验收

1. 安装并打开运行器，确认首次启动为空壳。
2. 分别导入 `baobao.petpack`、`feifei.petpack` 和 `starter-play-kit.itempack`。
3. 在“宠物小屋”中分别显示或隐藏包包、菲菲，并点击卡片切换当前互动对象。
4. 完成分部位摸摸、投喂、玩具、手动取消与亲密度解锁。
5. 把宠物拖到一个普通窗口顶边，确认行走；移动或关闭该窗口，确认跟随或安全下落。
6. 从内容包管理或系统托盘退出，再次启动，确认显隐、位置与亲密度仍在。

本 Alpha 暂无商业代码签名。Windows SmartScreen 可能显示“未知发布者”，请只从本仓库 Release 下载，并先核对 SHA-256。
