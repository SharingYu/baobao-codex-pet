# Pet Desktop Companion v0.3.1-alpha

这是面向录屏、在线视频与本地播放器并发场景的稳定性修复版本，继续兼容 v0.3.0 的宠物包、道具包、位置和亲密度存档。

## 修复内容

- 透明 Canvas 改为与 Chromium 合成器同步提交，提升 Windows 屏幕捕获可见性。
- 整屏渲染从显示器刷新率降为 30fps，并按视口限制像素预算，避免高 DPI 屏幕上的超大纹理持续重绘。
- 下一帧在更新与绘制前预先安排；单帧异常不再让动画循环永久停止。
- Canvas 上下文丢失后自动等待恢复并重新初始化画布。
- 透明窗口从 `screen-saver` 层级调整为标准 `floating` 层级，减少与全屏视频和硬件叠加层的冲突。
- 显式关闭 Windows 内容捕获保护；使用“显示器/屏幕捕获”时宠物可以进入录屏。
- 监听渲染器无响应、渲染进程退出和 GPU 进程退出，自动重载宠物舞台并写入 `diagnostics.log`。
- 托盘新增“修复卡顿（重载宠物）”，允许用户主动恢复舞台而不丢失宠物与亲密度。

## 验证结果

- 两路循环视频同时解码期间，真实操作录制连续完成 124 帧，包包、菲菲、投喂和玩具画面均可见。
- 同一台测试机器上，Electron GPU 与渲染进程的 4 秒 CPU 时间从旧版约 1.75 秒降至约 0.454 秒。
- 主动终止测试版 GPU 进程后，应用约 1.2 秒自动恢复，随后重新捕获到宠物和完整宠物小屋。
