# v0.1.0-alpha · 包包与菲菲闭环版

这是“真实宠物桌伴”的首个可安装 Windows 验证版，目标不是功能堆叠，而是跑通一条真实定制宠物的完整交付链路。

## 已完成

- Windows x64 NSIS 安装程序。
- 包包、菲菲双宠透明桌面陪伴。
- 摸摸、拖动、三种食物、小球、逗猫棒和纸箱。
- 安静模式、托盘显隐/退出、本地状态恢复。
- `.petpack` v1 声明式格式、JSON Schema、转换/验证/打包/导入工具。
- 程序内选择 `.petpack` 并安全安装到用户目录，目录热刷新后立即出现。
- 路径穿越、符号链接、主动内容、资源哈希、图片尺寸与运行器兼容性等 15 项自动化安全/回归测试。

发布页附带的包包、菲菲 `.petpack` 是定制格式样例；安装程序已经内置两只宠物，无需重复导入。

## 已验证

- 包包与菲菲目录包、单文件包均通过验证。
- Renderer 生产构建通过。
- Electron 开发壳与解包应用均能持续启动且无 stderr。
- 安装程序已完成一次静默安装、启动与卸载回归，三个阶段退出码均正常。

## 已知限制

- 当前只提供 Windows x64；macOS 尚未打包。
- 安装包未使用商业代码签名证书，SmartScreen 可能显示未知发布者。
- 照片到角色动画仍是后台定制流程，尚未在客户端内自动生成。
- 投喂和玩具暂时复用现有开心/扑击动作，后续会为每只宠物补专属进食、睡觉和玩具动画。
- 首版以主显示器为舞台；同时显示大量宠物时尚未做性能保证。
- Alpha 只接受与 Codex v2 相同的 `192 × 208`、`8 × 11` 图集布局；导入其他布局会明确报错，不会生成错帧宠物。
