# Pet Desktop Companion v0.3.2-alpha

这是动作一致性、可调节性和长时间运行稳定性版本。运行器仍为空壳，包包、菲菲和道具继续作为独立内容包交付。

## 新功能

- 宠物小屋为每只宠物加入“大小”与“速度”滑杆，范围分别为 `60%-180%` 和 `0.5×-2×`，修改即时生效并独立持久化。
- 调整大小时保留脚底锚点，位于桌面或窗口平台上的宠物不会突然跳位。
- 移动速度同时影响桌面追逐、漫步、窗口平台行走和移动动画节奏。
- 无目标静息时按条件随机触发梳毛、腹部清洁、睡觉、伸懒腰、打哈欠或嗅闻。
- 按住拖动后立即切换“被抱起”动作，松开后安全回到桌面或窗口平台。

## 动作与宠物包

- `.petpack` 动画新增可选 `visualScale`、`offsetX` 和 `offsetY`，方向观察动作新增对应的 `lookScale` 与偏移字段。
- 包包、菲菲的跑动和观察动作已做视觉比例校准；新静息事件使用同一套已审核角色帧，不改变画风和身份特征。
- 旧宠物包保持兼容；未声明新字段时按 `1.0` 和零偏移播放。

## 稳定性

- 单只宠物更新或绘制失败会被隔离并节流记录，其他宠物和主循环继续运行。
- 非有限坐标、非法大小/速度输入会被归一化或安全恢复。
- 取消交互、目录重载或进入安静模式时会强制释放拖拽状态与指针捕获，避免宠物永久卡在抱起状态。
- 新增 20,000 步混合动作压力测试，并完成完整语法、包格式、渲染、平台和交互回归。
