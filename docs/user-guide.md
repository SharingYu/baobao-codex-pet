# Windows 使用指南

## 1. 安装和打开

从 GitHub Release `v0.2.0-alpha` 下载以下五个文件：

- `PetDesktop-0.2.0-alpha-x64.exe`
- `baobao.petpack`
- `feifei.petpack`
- `starter-play-kit.itempack`
- `SHA256SUMS-v0.2.0-alpha.txt`

运行安装器后，从桌面快捷方式或 Windows“开始”菜单打开 **Pet Desktop Companion**。程序已在运行时，再次打开快捷方式会唤醒现有实例，不会启动第二份。

本公开 Alpha 尚未使用商业代码签名，SmartScreen 可能显示“未知发布者”。请只从本仓库 Release 下载，并在 PowerShell 中核对安装包：

```powershell
Get-FileHash .\PetDesktop-0.2.0-alpha-x64.exe -Algorithm SHA256
```

结果与 `SHA256SUMS-v0.2.0-alpha.txt` 一致时，可选择“更多信息”→“仍要运行”。

## 2. 导入包包、菲菲和道具

1. 首次启动会显示空壳卡片。点击“导入宠物包”，选择 `baobao.petpack`。
2. 点击底部最右侧的内容包管理按钮，再次选择“导入宠物包”，导入 `feifei.petpack`。
3. 在同一管理区点击“导入道具包”，选择 `starter-play-kit.itempack`。
4. 导入后，内容包管理区会分别列出两只宠物和起步道具包。

同一 ID 的内容包不会覆盖现有安装。升级 Alpha 内容包时，先在内容包管理区移除旧包，再导入新包。

## 3. 使用互动条

- **摸摸**：触发最近一只宠物的开心反馈；也可直接点击宠物。
- **拖动**：按住宠物并移动，把它放到喜欢的位置。
- **投喂**：选择鲑鱼零食并放到桌面，宠物会靠近并接受。
- **玩具**：选择毛线球、逗玩道具或纸箱小屋。逗玩模式会在 30 秒后自动收起。
- **边缘**：让宠物靠近屏幕工作区底边、沿边缘跑动，再跳回桌面。
- **安静**：暂停主动玩耍，让宠物安稳陪伴。

“边缘”当前仅指显示器的屏幕工作区边缘，不会识别其他应用窗口、浏览器页面或页面内容。

## 4. 显示、隐藏与退出

程序常驻系统托盘，不在任务栏显示普通窗口。若看不到图标，先点击任务栏右下角的“显示隐藏的图标”箭头。

- 单击托盘图标：显示或隐藏宠物。
- 双击托盘图标：显示宠物和底部互动条。
- 右键托盘图标：显示/隐藏、切换安静模式、显示互动条或退出。

隐藏宠物不等于退出程序。正确退出有两种方式：

1. 点击底部内容包管理按钮，再点击“退出程序”；
2. 右键系统托盘图标，选择“退出”。

若界面看起来没有响应，先尝试托盘“显示互动条”或“退出”。托盘也无响应时，按 `Ctrl + Shift + Esc` 打开任务管理器，结束 **Pet Desktop Companion**，再从快捷方式重新打开。

## 5. 卸载和本地数据

在 Windows“设置”→“应用”→“已安装的应用”中找到 **Pet Desktop Companion** 并选择“卸载”。

默认卸载会保留已导入宠物、道具和桌面状态，方便重装后继续使用。若希望彻底清除，请先退出程序，再删除：

```text
%APPDATA%\pet-desktop-companion
```

删除该目录会永久移除所有本地宠物包、道具包、位置和安静模式状态。
