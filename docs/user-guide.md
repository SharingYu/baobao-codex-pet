# Windows 使用指南

## 1. 下载、安装和打开

从 GitHub Release `v0.3.1-alpha` 下载：

- `PetDesktop-0.3.1-alpha-x64.exe`：Windows 安装版；
- `PetDesktop-Portable-0.3.1-alpha-x64.exe`：免安装便携版，可选；
- `baobao.petpack`；
- `feifei.petpack`；
- `starter-play-kit.itempack`；
- `SHA256SUMS-v0.3.1-alpha.txt`。

运行安装器后，从桌面快捷方式或 Windows“开始”菜单打开 **Pet Desktop Companion**。如果程序已经运行，再次打开快捷方式只会唤醒现有实例，不会启动第二份。

本公开 Alpha 尚未使用商业代码签名，SmartScreen 可能显示“未知发布者”。请只从本仓库 Release 下载，并在 PowerShell 中核对文件：

```powershell
Get-FileHash .\PetDesktop-0.3.1-alpha-x64.exe -Algorithm SHA256
```

结果与 `SHA256SUMS-v0.3.1-alpha.txt` 一致时，可选择“更多信息”→“仍要运行”。

## 2. 完整首次使用流程

1. 首次启动会显示空壳卡片。点击“导入宠物包”，选择 `baobao.petpack`。
2. 打开互动条“选择宠物/当前：…”进入“宠物小屋”，点击“添加宠物”导入 `feifei.petpack`。
3. 点击底部最右侧的内容包管理按钮，选择“导入道具包”，导入 `starter-play-kit.itempack`。
4. 在“宠物小屋”点击宠物卡片，把它设为当前互动对象；投喂、玩具和亲密度会作用于当前宠物。
5. 使用每张卡片的“桌面显示”开关控制它是“陪伴中”还是“休息中”。包包和菲菲可以同时出现，也可以只显示其中一只。

同一 ID 的内容包不会直接覆盖已安装版本。升级 Alpha 内容包时，先在内容包管理区移除旧包，再导入新包；该宠物的亲密度和位置记录会保留。

## 3. 摸摸、投喂和玩具

- **摸摸**：先点击一次“摸摸”，鼠标移到宠物身上会变成手掌；再点击头、背、尾巴或身体，触发对应反应。按 `Esc`、再次点击“摸摸”或等待 15 秒可取消手掌模式。
- **拖动**：按住宠物并移动，把它放到喜欢的位置；松手后会自动寻找桌面或可用窗口顶边落脚。
- **投喂**：打开“投喂”选择食物，点击或拖到桌面。同一时间只保留一份食物；再次打开菜单点击“收起当前食物”可立即取消，45 秒未吃会自动收起。
- **玩具**：打开“玩具”选择毛线球、逗猫棒或纸箱小屋。同一时间只使用一件；再次选择当前玩具或点击“收起当前玩具”可立即取消。选择逗猫棒后，移动鼠标即可引导当前宠物追逐；逗猫棒、毛线球和纸箱分别在 30、45、90 秒后自动结束。
- **安静**：暂停主动互动并收起临时食物、玩具和手掌模式，让宠物安稳陪伴。

## 4. 窗口平台互动

“沿边缘行走”不再需要主动按钮。把宠物拖到普通 Windows 窗口的顶部边缘，命中后它会自动吸附、沿平台行走并跟随窗口移动。窗口关闭、移走或平台互动关闭时，宠物会安全落回桌面。

窗口平台功能可以在“宠物”面板中随时关闭。它只读取顶层窗口的几何矩形和进程编号，不读取窗口标题、正文、网页 DOM、控件内容、截图、键盘输入，也不使用 OCR 或无障碍树。

## 5. 亲密度与解锁

包包和菲菲分别保存自己的亲密度、等级和每日次数：

- 摸头 `+3`，摸背或身体 `+2`，摸尾巴 `+1`；同一部位 30 秒内重复摸仍有动画，但不重复加分。
- 成功投喂 `+8`。
- 玩乐持续至少 15 秒且有效互动至少 3 次时 `+10`。
- 每只宠物每天最多计入摸摸 5 次、投喂 3 次、玩乐 3 次。

亲密度达到 `0 / 40 / 120 / 300 / 600` 时依次进入“初见、熟悉、亲近、默契、挚友”。Lv.1 可用鲑鱼小零食和珊瑚毛线球，Lv.2 解锁纸箱小屋，Lv.3 解锁奶香鸡肉冻干，Lv.4 解锁逗猫棒；Lv.5 当前作为成长里程碑，服装能力计划在后续版本加入。

## 6. 显示、隐藏与退出

程序常驻系统托盘，不在任务栏显示普通窗口。若看不到图标，先点击任务栏右下角的“显示隐藏的图标”箭头。

- 单击托盘图标：显示或隐藏宠物；
- 双击托盘图标：显示宠物和底部互动条；
- 右键托盘图标：显示/隐藏、切换安静模式、显示互动条、修复卡顿或退出。

隐藏宠物不等于退出程序。正确退出有两种方式：

1. 点击底部内容包管理按钮，再点击“退出程序”；
2. 右键系统托盘图标，选择“退出”。

若界面看起来没有响应，先选择托盘“修复卡顿（重载宠物）”。v0.3.1 也会在渲染器无响应或 GPU 进程意外退出时自动恢复；诊断记录保存在 `%APPDATA%\pet-desktop-companion\diagnostics.log`。

## 7. 录屏与视频应用兼容

v0.3.1 将透明宠物舞台限制为 30fps 和受控像素预算，并在 Canvas、渲染进程或 GPU 上下文异常后自动续帧或重载，降低与浏览器视频、播放器和录屏工具同时运行时的资源竞争。

录制时请选择录屏软件的“显示器捕获 / 屏幕捕获 / 全屏捕获”。“窗口捕获”通常只录制被选择应用自己的窗口，无法包含作为独立透明窗口运行的桌面宠物；这是 Windows 窗口捕获模型的边界，不代表宠物没有渲染。程序显式保持内容保护关闭，因此标准屏幕捕获可以包含宠物。

## 8. 卸载和本地数据

在 Windows“设置”→“应用”→“已安装的应用”中找到 **Pet Desktop Companion** 并选择“卸载”。

默认卸载会保留已导入宠物、道具、位置和亲密度，方便重装后继续使用。若希望彻底清除，请先退出程序，再删除：

```text
%APPDATA%\pet-desktop-companion
```

删除该目录会永久移除所有本地宠物包、道具包和进度。
