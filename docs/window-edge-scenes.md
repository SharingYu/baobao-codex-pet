# 窗口边缘场景与隐私边界

## 已实现：屏幕工作区边缘

运行器已把透明覆盖层对应的工作区当作第一套“场景轨道”：宠物会先靠近底部边缘，再沿边缘横向跑向左右端，最后以抛物线跳回桌面。它只使用运行器已知的工作区尺寸，不读取任何其他程序的数据。

可扩展的场景：

- 在任务栏上方慢跑、探头或打盹。
- 从屏幕左右边缘探出后跳下。
- 在浮动道具旁等待、追球或钻进藏身处。
- 多只宠物相遇后让路、一起追同一颗球或共享纸箱。

## 下一阶段：前台窗口边框轨道

Windows 适配器可在用户启用“跟随前台窗口边缘”后，仅提供：

```ts
type WindowRail = {
  source: 'foreground-window';
  bounds: { x: number; y: number; width: number; height: number };
  state: 'normal' | 'maximized' | 'minimized' | 'fullscreen';
  displayId: string;
};
```

渲染器把矩形转换为标题栏、左/右边、底边和角落跳台；宠物的跑跳只发生在这些几何轨道上。窗口移动、最大化或最小化时，轨道立即更新或隐藏。

## 明确不做的默认行为

- 不截屏、不 OCR、不读取网页 DOM，不查看聊天、文档、IDE 或浏览器正文。
- 不上传窗口几何、窗口标题或交互记录。
- 不在全屏会议、游戏或演示时主动遮挡；默认退回安静模式。

“识别页面内容再互动”只能作为未来的按应用可选功能：用户要明确选择应用、查看本地处理说明，并能随时关闭或清除数据。它不属于默认运行器，也不应成为售卖宠物包的前置权限。
