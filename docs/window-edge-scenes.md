# 窗口平台场景与隐私边界

## 已实现：Windows 顶层窗口平台

v0.3 把普通顶层窗口的顶部边缘变成被动平台。用户无需点击“边缘”按钮：把宠物拖到窗口顶边并松手，运行器会命中附近平台，使宠物吸附、沿顶边行走并跟随窗口移动。窗口关闭、移走、最小化或平台开关关闭时，宠物会进入下落并安全回到桌面。

最大化、全屏、隐藏、最小化、工具型、点击穿透以及运行器自身窗口不会成为平台，避免会议、游戏和全屏演示被遮挡。

## 几何 watcher

用户开启窗口平台互动后，Windows 主进程才启动隐藏的 PowerShell watcher。C# 窗口枚举只在该次 watcher 启动时编译一次，随后约每 120ms 输出一行 JSON；关闭开关会立即结束子进程、清除缓存和重启计时。每条记录固定为：

```ts
type WindowGeometry = {
  hwnd: string;
  pid: number;
  left: number;
  top: number;
  right: number;
  bottom: number;
};
```

主进程把物理像素映射为 Electron DIP 坐标，再转换为透明覆盖层的局部坐标。渲染器只接收几何平台，不接触原始系统 API。watcher 有 256KB 单行上限、启动/停滞检测、单实例代际保护和 250ms–8s 指数退避重启；失败时保留短期缓存或退化为桌面地面，不阻塞宠物主循环。

## 明确的隐私边界

- 不调用窗口标题 API，不读取网页 DOM、聊天、文档、IDE 或浏览器正文。
- 不截屏、不 OCR、不使用 UI Automation，不监听键盘输入。
- 不上传窗口几何、进程编号或互动记录。
- IPC 会丢弃任何不在 `hwnd/pid/left/top/right/bottom` 白名单中的字段。
- 用户可在“宠物”面板随时关闭窗口平台互动；关闭后不会继续枚举窗口。

未来的“识别页面内容再互动”只能作为独立、按应用授权的可选能力，必须展示本地处理说明，并允许随时关闭和清除数据。它不属于默认运行器，也不是售卖宠物包的前置权限。

## 可继续扩展的场景

- 在任务栏上方慢跑、探头或打盹；
- 在两个可见窗口之间小跳；
- 多只宠物在同一平台让路或并排行走；
- 结合已安装玩具，在窗口平台上追球或等待。

这些扩展仍应只依赖几何和声明式内容包，不扩大默认隐私权限。
