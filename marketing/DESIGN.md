# 首批内测宣传素材设计规范

## 目标

这套素材用于招募第一批真实内测用户，重点说明三件事：

1. 首批内测阶段提供免费定制专属桌面宠物。
2. 参与者需要提供自己的宠物照片，并在体验后给出真实反馈。
3. 分享完全自愿，只使用“愿意的话，也欢迎随缘分享”。

不得使用虚构名额、倒计时、用户评价、成功案例、交付时限、还原度保证或其他未经验证的承诺。

## 文案单一来源

marketing/copy-data.mjs 是静态图和视频共用的唯一机器可读文案源；marketing/copy.md 是供人工审核的逐字镜像，不再承担第二份运行时配置。

静态渲染器直接导入中央文案对象，视频则只从导出器注入的 config.copy 读取可见文本。--check 与正式导出执行同一组约束：校验版本、镜像覆盖、未知文案、模板引用与未使用条目；发现模板内联可见文案时立即失败。

## 视觉系统

整体延续应用的温暖、克制与手作感，避免游戏广告式高饱和堆叠。

- Warm cream：`#FFF7EB`，主背景。
- Soft cream：`#F8EAD7`，卡片和分区。
- Coral：`#C7664F`，主 CTA、内测标签与强调。
- Sage：`#8EA58C`，流程节点与次级装饰。
- Cobalt：`#3157C8`，仅用于“当前选择”或极少量状态点，不作为大面积背景。
- Ink：`#24211F`，正文和主要标题。
- Muted ink：`#6F6861`，说明文字。

排版优先使用 Microsoft YaHei / Noto Sans CJK SC / sans-serif。标题紧凑、正文留白充分；圆角统一为 24–40px，细描边使用 `#E8D8C4`。

| --- | ---: | --- |
| `internal-test-portrait-01.png` | 1080×1440 | 首发招募主视觉 |

PNG 由同一 SVG 模板和 `@resvg/resvg-js` 确定性渲染。视频场景、时长、坐标和文案固定；当前 Windows Alpha 为稳定导出优先使用 WebM/VP8，若后续环境中的 MP4 编码链经过同等级 QA，可再增加 MP4 交付。

## 真实素材边界

允许且仅允许读取以下产品素材：

- `docs/assets/desktop-v03.png`：最终新版程序的真实截图，固定路径，缺失时整条导出明确失败。
- `petpacks/baobao/assets/atlas.webp` 与对应 manifest。
- `petpacks/feifei/assets/atlas.webp` 与对应 manifest。
- `itempacks/starter-play-kit/manifest.json` 中已声明的真实道具资产。

禁止读取、复制或重新发布用户提供的猫照片、微信临时目录、`runs/` 中间素材或其他参考图片。宣传图中的程序画面必须直接使用真实截图，不绘制、拼接或伪造应用界面。

## 视频脚本（14 秒）

- `0–2.4s`：首批内测；免费定制专属桌面宠物。
- `2.4–5.8s`：展示真实程序截图；包包与菲菲轻微进入画面。
- `5.8–9.2s`：摸摸、投喂、玩具、亲密度；只展示真实 atlas 与道具资源。
- `9.2–12.0s`：你提供宠物照片；体验后告诉我真实感受。
- `12.0–14.0s`：愿意的话，也欢迎随缘分享；首批内测。

镜头只做平移、缩放、淡入与真实 sprite 帧切换，不模拟鼠标点击结果，不制造不存在的界面或用户行为。

## QA

- 输出尺寸必须完全匹配固定规格。
- 文案必须来自 `marketing/copy-data.mjs`，且通过与 `marketing/copy.md` 的逐字镜像校验。
- atlas 与道具文件必须通过 manifest 中的 bytes 与 SHA-256 校验。
- 输出 `marketing/out/manifest.json`，记录输入和输出 SHA-256、尺寸、视频容器与时长。
- 截图缺失时不得使用 `desktop-alpha.png` 或任何替代图继续导出。
