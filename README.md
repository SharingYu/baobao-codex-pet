# Baobao & Feifei — Codex Pets

两只可加载到 Codex 的自定义 v2 动画宠物：

- **包包 Baobao**：金色长毛猫，白色荷叶边铃铛项圈。
- **菲菲 Feifei**：蓝金三花英短，白胸粉鼻。

每只宠物均包含 Codex v2 所需的 `1536 × 2288`、11 行动画图集和 16 个视线方向。

## 安装

将 `pets/baobao` 与 `pets/feifei` 复制到你的 Codex 宠物目录：

```text
%USERPROFILE%\.codex\pets\
```

重启 Codex 或新开一个任务后，在宠物设置中选择它们。

## Privacy

本仓库仅包含由宠物照片重新绘制的动画图集，不包含原始照片、私人视频或社交平台水印。
